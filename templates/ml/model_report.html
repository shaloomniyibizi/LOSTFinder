    How the models are built

    {% if request.user.is_staff %}
    {% csrf_token %}
    {% endif %}
    1. Read data from the API. manage.py fetch_api_data signs in to /api/v1/auth/token/ and downloads every report and decided match from /api/v1/ml/training-data/.
    2. Add synthetic data. Real decided matches are few, so ml/synthetic.py simulates owners and finders describing the same objects in their own words, plus look-alike objects as negatives.
    3. Train and compare. manage.py train_model fits logistic regression and a random forest on 80% of the data, keeps the one with the better F1 on the other 20%, and compares it with the old rule-based score.
    4. Deploy. The model is saved to ml/artifacts/, loaded by Django, and scores every new report as it is saved (web form or API).
